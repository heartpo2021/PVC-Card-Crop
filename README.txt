PVC Card Studio - Drag & Drop UI Update

Double-click RUN_PVC_TOOL.bat (requires Windows Python and internet for first dependency installation).
Drag PDFs into the white box, or use Add PDFs/Add Folder.
Press START manually to process; dropping files does NOT auto-start.
Save folder and DPI are editable. PDF password prompts remain supported.

This update retains the previous PDF detection and export logic.
Quality improvement is OFF by default to avoid unnecessary blur.
For drag and drop, tkinterdnd2 must install successfully.
Not tested on a Windows PC or printer; Python syntax has been checked.
